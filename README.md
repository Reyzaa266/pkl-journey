# LaporPKL Cloud
1. `npm install`
2. Buat project Supabase.
3. Jalankan seluruh `supabase/schema.sql` di SQL Editor.
4. Salin `.env.example` menjadi `.env`, isi URL dan anon/publishable key.
5. `npm run dev`
6. Buka alamat localhost yang tampil.
Akun baru otomatis role `student`. Untuk guru/admin, ubah kolom `role` pada `profiles`.
